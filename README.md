# Telegram-бот поиска музыки (GitHub + Vercel)

Пишешь название или исполнителя, бот показывает кнопки с вариантами, нажимаешь, получаешь аудио.
Работает через webhook на Vercel: свой сервер и Python на компьютере не нужны, бесплатно, 24/7.

Источники:
- 🟣 **Audius**: работает сразу, ключи не нужны.
- 🟡 **Яндекс Музыка**: необязательно, нужен токен аккаунта с подпиской Плюс (см. ниже).

SoundCloud здесь не подключён: ему нужны ffmpeg и скачивание потоков, а на Vercel это не работает.

## Структура

```
api/webhook.py   код бота
requirements.txt зависимости
vercel.json      настройки функции
.gitignore
README.md
```

## Установка

### 1. Токен бота
В Telegram открой @BotFather, отправь `/newbot`, придумай имя и username (на `bot` в конце). Скопируй токен.

### 2. GitHub
Создай **приватный** репозиторий и загрузи в него всю папку проекта целиком (перетащи файлы и папку `api` на страницу репозитория, кнопка Add file -> Upload files). Файла `.env` в проекте нет, токены в код не вставляй.

### 3. Vercel
1. vercel.com -> войти через GitHub -> **Add New -> Project** -> выбери репозиторий.
2. Раскрой **Environment Variables** и добавь:
   - `BOT_TOKEN` : токен от BotFather
   - `WEBHOOK_SECRET` : любая случайная строка из латинских букв и цифр (например `k3j9x8s7d6f5g4h3`)
   - `YANDEX_MUSIC_TOKEN` : по желанию, токен Яндекс Музыки
3. Нажми **Deploy**. Получишь адрес вида `https://my-bot.vercel.app`.

### 4. Подключи webhook
Открой в браузере (подставь свои значения):

```
https://api.telegram.org/botТОКЕН_БОТА/setWebhook?url=https://my-bot.vercel.app/api/webhook&secret_token=ТВОЯ_СТРОКА_ИЗ_WEBHOOK_SECRET
```

Должно ответить `{"ok":true,"result":true,"description":"Webhook was set"}`.

### 5. Проверь
Открой бота в Telegram, нажми `/start` и напиши название песни.

Если добавляешь или меняешь переменные позже, нажми на Vercel Deployments -> ... -> **Redeploy**.

## Токен Яндекс Музыки (по желанию)
Открой, войдя в Яндекс: `https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabbbdc6cd418abb4b39c32c41195d`, нажми «Разрешить» и скопируй значение `access_token=...` из адресной строки. Токен даёт доступ к аккаунту, никому не показывай.

## Важно знать
- Яндекс может не отдавать файлы серверам Vercel (зарубежные IP, региональные ограничения). Если Яндекс-кнопки не работают, бот всё равно будет искать и играть Audius.
- Функции на Vercel имеют лимит времени (в `vercel.json` стоит 60 секунд), файлы больше ~50 МБ отправить нельзя.
- Каталог Audius независимых артистов, мейнстримных хитов там мало.
- Скачивай и распространяй только то, на что у тебя есть права.

## Если не работает
- Проверить webhook: `https://api.telegram.org/botТОКЕН/getWebhookInfo` (поле `last_error_message`).
- Логи функции: Vercel -> проект -> Logs.
